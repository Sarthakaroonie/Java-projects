# Java Programming and Object-Oriented Software Design

A collection of modular, production-style Java applications covering language fundamentals, object-oriented programming, file-based persistence, data structures, concurrency, and structural design patterns.

---

## Projects Overview

| Module Directory | Core Concepts & Features |
| :--- | :--- |
| `01-number-guessing-game/` | Standard I/O, loop structures, conditional branching, static methods |
| `02-matrix-operations/` | Multi-dimensional arrays, nested iteration, bounds validation |
| `03-text-analytics-engine/` | `StringBuilder`, String manipulation, regular expressions, tokenization |
| `04-expense-visualizer/` | Primitive array processing, formatted CLI output (`printf`), data sanitization |
| `05-student-gpa-system/` | Encapsulation, access control, explicit constructors, domain modeling |
| `06-contact-directory-csv/` | Persistent File I/O (`BufferedReader`/`PrintWriter`), CSV parsing, exception handling |
| `07-task-todo-serialization/` | Object serialization (`Serializable`), `java.time` API, state persistence |
| `08-unit-converter-engine/` | Enumerations (`enum`), typed constants, switch expressions, method overloading |
| `09-atm-banking-engine/` | Custom exception hierarchies, transactional integrity, defensive copying |
| `10-fleet-rental-registry/` | Inheritance hierarchies, abstract base classes, dynamic method dispatch |
| `11-retail-inventory-strategy/` | Java Collections Framework (`HashMap`, `ArrayList`), Strategy design pattern |
| `12-generic-key-value-store/` | Generics (`<K, V>`), collision handling, data structure implementation |
| `13-rpg-battle-simulator/` | Interface contracts, polymorphic runtime dispatch, state machine architecture |
| `14-multithreaded-banking/` | Thread management, synchronization primitives, race-condition mitigation |
| `15-producer-consumer-pipeline/`| Concurrency (`BlockingQueue`, `wait`/`notify`), thread pooling (`ExecutorService`) |
| `16-markdown-json-parser/` | Factory Method pattern, recursive token parsing, decoupled system architecture |

---

## Technical Specifications

* **Language Standard:** Java SE 17 (LTS) or higher
* **Compilation / Build:** Native `javac` / Standard IDE toolchains (IntelliJ IDEA, Eclipse, VS Code)
* **Version Control:** Git
